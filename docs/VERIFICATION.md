## Локальные проверки

Из корня проекта после `npm ci`:

```powershell
npm test
npm run lint
npm run build
```

Тесты проверяют порядок изображений, оба алгоритма переноса, доработку, ограничения файлов, ошибки API и моста, отсутствие автоматических повторов, исключение локальных данных из экспорта и перенос сгенерированных файлов мостом. Внешняя генерация этими командами не запускается.

## Отдельный сквозной тест подписки

Этот тест **запускает реальную генерацию и использует лимит**. Он не входит в `npm test`.

1. Запустите приложение на порту 3000 и подтвердите вход Codex.
2. Из корня проекта выполните:
   ```powershell
   node --import tsx tests/live-subscription.ts
   ```
3. При успехе изображение появится в `output/test-subscription-bridge.png`, отчёт — в `output/subscription-verification.json`. При ошибке её текст появится в терминале.

Используются опубликованные персонаж и поза из `docs/examples/direct-vs-guided/`. Повторяйте тест только намеренно: автоматических повторов нет.

## Практические ограничения

- Перенос не гарантирует совпадения кистей, стоп, лица, ракурса и деталей костюма.
- Направляющая тоже генерируется и может внести ошибку до финального переноса.
- Через Codex пропорции задаются текстом; точные модель, качество и пиксельный размер не выбираются.
- Один результат через манекен требует двух этапов. Варианты и доработка увеличивают число генераций.
- Постоянной истории результатов в интерфейсе нет; сохраняйте нужные изображения.
- Приложение рассчитано на локальное использование одним пользователем; сервер слушает `127.0.0.1`.
