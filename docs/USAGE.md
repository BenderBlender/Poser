# Инструкция по использованию Poser

[Описание проекта](../README.md) · [Примеры](EXAMPLES.md) · [Проверки](VERIFICATION.md)

## 1. Установка, запуск и остановка

Понадобятся Windows, браузер и **Node.js 22.15 или новее**. Для установки библиотек и генерации нужен интернет.

1. На [странице репозитория](https://github.com/BenderBlender/Poser) выберите **Code → Download ZIP**.
2. Распакуйте архив в отдельную папку. Не запускайте приложение внутри архива.
3. Дважды щёлкните **Start-Pose-Studio.bat**. Он установит отсутствующие библиотеки, соберёт приложение и откроет браузер.
4. Если вкладка не появилась, откройте **http://127.0.0.1:3000** вручную.

Приложение работает в фоне. **Stop-Pose-Studio.bat** останавливает запущенный через BAT экземпляр и его текущую генерацию. Закрытие браузера не завершает работу сервера. Повторное открытие Start не создаёт второй экземпляр; повторное открытие Stop после остановки допустимо.

Если приложение запущено через `npm run dev` или `npm start`, завершайте его через `Ctrl+C` в том же терминале. BAT-файл остановки управляет экземпляром, который отслеживает собственный запуск.

## 2. Подключение генератора

### Через подписку Codex

Этот вариант выбран по умолчанию. Нужен установленный Codex с входом через ChatGPT и доступной генерацией изображений. Само наличие Codex не гарантирует такой доступ.

1. Войдите в Codex через ChatGPT. Для входа из командной строки используется `codex login`.
2. Запустите Poser и выберите **«Через подписку Codex»**.
3. Дождитесь проверки подключения. Если вход не подтверждён, исправьте причину и нажмите **«Обновить статус»**.

Если автоматический поиск не находит Codex, скопируйте `.env.example` в `.env.local` рядом с `package.json` и задайте путь:

```dotenv
CODEX_IMAGE_CODEX_PATH="C:/path/to/codex.exe"
PORT=3000
```

Замените путь на реальное расположение `codex.exe` и перезапустите Poser. Проверьте, что файл не назван `.env.local.txt`.

API-ключ не нужен. Мост использует существующий вход Codex; переносить файлы авторизации в папку приложения не требуется. Подтверждение входа не показывает остаток лимита — он проверяется при генерации.

### OpenAI API

1. Скопируйте `.env.example` в `.env.local` рядом с `package.json`.
2. Укажите свой ключ:
   ```dotenv
   OPENAI_API_KEY=YOUR_API_KEY
   PORT=3000
   CODEX_IMAGE_CODEX_PATH=auto
   ```
3. Перезапустите приложение и выберите **«OpenAI API»**.

Ключ хранится на локальном сервере. Заполненный `.env.local` не нужно публиковать. Приложение использует выбранное подключение и не переключается на другой способ автоматически. Доступность моделей и настроек зависит от API-аккаунта. Реальный API-вызов в исходной проверке пакета не выполнялся — см. [статус проверки](VERIFICATION.md).

### Вручную в ChatGPT

**«Подготовить для ChatGPT»** работает без API-ключа и подключённого Codex. Кнопка создаёт текст задания; сама генерация выполняется после ручной отправки в ChatGPT. Порядок действий — в разделе 7 ниже.

## 3. Подготовка исходников

| Поле | Что загрузить | Назначение |
|---|---|---|
| **1. Загрузите персонажа** | Портрет, изображение в полный рост или лист персонажа | Внешность, стиль, одежда и детали |
| **2. Загрузите позу** | Фото или рисунок с нужным положением тела | Поза, положение конечностей и ракурс |
| **1.5. Добавьте детали** — необязательно | Крупные планы лица, одежды, аксессуаров | Уточнение внешности того же персонажа |

Файлы выбираются щелчком или перетаскиваются в поле. В демонстрации с девушкой, лежащей с поднятыми ногами, **фотографию нужно загрузить в поле позы**. Персонаж задаётся отдельно.

Выбирайте позу с хорошо видимыми суставами, кистями и стопами. Если людей несколько, заранее подготовьте кадр с нужным человеком. Не обрезайте важные конечности. В приложении нет отдельного редактора кадрирования.

Форматы: **PNG, JPEG/JFIF и WebP**. Ограничения: **12 МиБ на файл**, **8 дополнительных референсов**, **60 МиБ изображений в одном запросе**.

## 4. Прямой перенос

1. Выберите подключение, загрузите персонажа и позу.
2. Выберите **«Прямой»** — это исходный режим.
3. При необходимости заполните **«Опишите детали (необязательно)»**. Например: «Сохрани одежду и рисунок ткани персонажа. Покажи обе стопы целиком. Светлый фон».
4. Выберите пропорции и число вариантов. Для первой попытки достаточно одного.
5. Нажмите **«Сгенерировать позу»** и дождитесь результата.

Генератор получает персонажа первым, исходную позу второй, затем дополнительные изображения деталей. Для одного результата нужен один этап генерации.

Опция **«Включить художественную интеграцию»** помогает согласовать стиль и композицию, но поза и детали могут отличаться от референса. Если важнее точность позы, начните с выключенной опции.

## 5. Манекен с сеткой

1. Загрузите персонажа и позу.
2. Выберите **«С направляющей»**.
3. Для сетки тела и пола выберите **«Перспектива + Каркас»** — это исходный выбор направляющей.
4. Задайте остальные параметры и нажмите **«Сгенерировать позу»**.
5. Приложение создаст направляющую, покажет промежуточное изображение и автоматически выполнит перенос на персонажа.

На первом этапе передаётся фото позы. На втором — персонаж, манекен и дополнительные детали. **Исходное фото позы во второй запрос не добавляется.** Линии манекена служат ориентирами и не должны появляться на итоговом персонаже.

| Тип направляющей | Содержание |
|---|---|
| **Стикмен** | Схема суставов и конечностей |
| **3D-манекен** | Объёмная фигура |
| **Перспективная сетка** | Манекен и сетка плоскости опоры |
| **Каркасная сетка** | Манекен с сеткой поверхности тела |
| **Перспектива + Каркас** | Сетка поверхности тела и перспективная сетка пола |

Для одного результата нужны два этапа. Через подписку несколько вариантов генерируются последовательно: для трёх результатов — одна направляющая и три финальные генерации. Каждая доработка запускает ещё одну генерацию.

Промежуточный манекен тоже может ошибиться. Сравните его с фотографией; при заметном расхождении попробуйте другой референс или прямой режим. [Сохранённое сравнение](EXAMPLES.md) не показывает гарантированного преимущества одного способа.

## 6. Просмотр, сохранение и доработка

- **Увеличить изображение** открывает крупный просмотр.
- Кнопка скачивания сохраняет выбранный результат на компьютер.
- **Улучшить детали** открывает **«4. Уточнение результата»**.

В окне уточнения:

1. Опишите конкретное изменение: «Исправь положение левой кисти, сохрани лицо, одежду и остальную позу».
2. При необходимости отметьте ориентиры **«Персонаж (Стиль)»**, **«Поза (Оригинал)»**, **«Поза (Скелет)»**, если манекен создан.
3. При необходимости добавьте новые изображения деталей.
4. Нажмите **«Улучшить»**. **«Отмена»** закрывает окно доработки.
5. После завершения **«Отменить улучшение»** возвращает предыдущую версию выбранной картинки — только один шаг, не полную историю.

Доработка может изменить больше, чем указано в тексте. Сохраняйте удачные варианты перед следующими изменениями. Обновление вкладки сбрасывает подборку в интерфейсе.

## 7. Ручная отправка в ChatGPT

1. Выберите алгоритм, пропорции и уточнения в Poser.
2. Нажмите **«Подготовить для ChatGPT»**.
3. Нажмите **«Копировать»** или **«Скачать .txt»**.

**Прямой перенос:** приложите в ChatGPT персонажа первым, фото позы вторым, затем дополнительные референсы. Отправьте подготовленный промпт вместе с ними.

**С направляющей:** сначала отправьте только фото позы и текст **«ЗАДАНИЕ 1 — СОЗДАТЬ МАНЕКЕН»**. Сохраните манекен. Затем откройте **новый чат**, приложите персонажа первым, манекен вторым, дополнительные детали после них и отправьте текст второго задания. Исходное фото позы на втором этапе не прикладывайте.

Результат скачивается из ChatGPT; автоматически обратно в Poser он не поступает.

## 8. Настройки изображения

Оба подключения предлагают **1:1, 3:4, 4:3, 9:16, 16:9** и **1–3 варианта**. Через Codex пропорции передаются текстом и не гарантируют точный пиксельный размер; выбор модели, качества и размера скрыт.

В API-режиме доступны модели из интерфейса, качество **«Быстрое» / «Среднее» / «Высокое»** и профили **1K / 2K / 4K**. Размеры запросов этой версии:

| Профиль | 1:1 | 3:4 | 4:3 | 9:16 | 16:9 |
|---|---:|---:|---:|---:|---:|
| 1K | 1024×1024 | 864×1152 | 1152×864 | 864×1536 | 1536×864 |
| 2K | 2048×2048 | 1536×2048 | 2048×1536 | 1152×2048 | 2048×1152 |
| 4K | 2880×2880 | 2448×3264 | 3264×2448 | 2160×3840 | 3840×2160 |

Это отправляемые параметры, а не подтверждение доступности всех сочетаний для любого API-аккаунта.

## 9. Где находятся файлы

| Путь от папки проекта | Содержимое |
|---|---|
| `output/subscription/` | Изображения, сохранённые мостом Codex |
| `.codex-inputs/` | Референсы и тексты запросов моста |
| `output/server.log` | Журнал сервера, запущенного через BAT |
| `output/server-error.log` | Ошибки такого запуска |
| `.env.local` | Локальные настройки и API-ключ |
| `docs/examples/` | Публичные демонстрации |

Результаты API сохраняйте кнопкой скачивания: постоянной галереи нет. Входы и результаты моста остаются на диске и автоматически не удаляются. Экспорт исходников исключает локальные настройки, рабочие изображения и журналы, но включает опубликованные примеры документации.

## 10. Если что-то не работает

| Ситуация | Что сделать |
|---|---|
| Сообщение о Node.js | Установите Node.js 22.15+ и повторите запуск |
| Не установились библиотеки | Проверьте интернет и повторите запуск; подробности видны в окне запуска |
| Codex не найден | Проверьте установку или задайте `CODEX_IMAGE_CODEX_PATH`, затем перезапустите приложение |
| Вход не подтверждён | Войдите в Codex через ChatGPT и обновите статус в Poser |
| Лимит исчерпан | Дождитесь восстановления лимита; автоматического повтора нет |
| API не подключён | Проверьте `.env.local` и `OPENAI_API_KEY`, затем перезапустите приложение |
| API отклоняет модель или параметры | Проверьте доступ к выбранной модели и поддерживаемым настройкам API-аккаунта |
| Генерация уже выполняется | Дождитесь завершения; одновременно выполняется одна задача через подписку |
| Неподдерживаемый или большой файл | Пересохраните в PNG/JPEG/WebP и уменьшите размер |
| Порт 3000 занят | Остановите предыдущий экземпляр или задайте другой `PORT` в `.env.local`; адрес после перезапуска изменится |
| Страница не открылась | Проверьте `output/server-error.log` и откройте локальный адрес вручную |
| Поза или внешность изменилась | Попробуйте конкретное уточнение, дополнительные детали персонажа, другой референс или второй алгоритм |

Остановка приложения прерывает текущую работу, но не возвращает использованный лимит. Для сообщения об ошибке достаточно её текста и выбранного режима; ключи и файлы авторизации не нужны.
